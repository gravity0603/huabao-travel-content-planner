# 华为画报旅行风光专项 Skill

`huabao-travel-content-planner` 用于华为杂志锁屏旅行风光内容的策划、审核和月报复盘。

## v0.4.0 的工作重点

- 先确认热点或节令依据，再筛可用封面。
- 最终候选只做自然异常、风光大片和有趣建筑。
- 历史冷知识作为景观/建筑的解释层，不单独凑品类。
- 最终候选必须同时有事实来源、图片/版权线索和锁屏画面判断。
- 标题追求自然中文，不把“也”、引号或问句当成公式。

详细工作流、输出格式和审核闸门见 [SKILL.md](SKILL.md)。跨月证据与策略见 [references/travel-strategy.md](references/travel-strategy.md)。

## 评测

评测用例位于 [evals/evals.json](evals/evals.json)，覆盖真实热点筛选、封面闸门、自然标题、来源审核和月报复盘。
