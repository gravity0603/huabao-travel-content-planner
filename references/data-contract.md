# 旅行专项数据契约

> 文档版本：v0.4.0
> 适配 Skill：v0.6.0

## 1. 按任务决定输入

| 任务 | 必需输入 |
|---|---|
| 批量策划、上线候选审核 | 原始素材库 CSV、已做标题表、近期已出选题；周数据与月报用于评分 |
| 标题表达优化 | 原始事实、首图题眼、原标题或候选标题 |
| 月报/周数据复盘 | 对应月报、周数据或用户提供的摘录 |
| 来源审核 | 待审核链接及其验证状态 |

只有批量策划和上线候选审核强制要求三方去重数据。前三项去重数据任一缺失时，输出：`无法完成三方概念级去重：缺少 <数据名称>。` 不得标“主推”。

## 2. 素材库优先与概念级去重

批量策划按以下顺序读取：

1. 原始素材库 CSV：按新增时间倒序，从最近新增链接开始。
2. 已做标题表。
3. 近期已出选题。
4. 最近周数据与最新月报。

对每条候选生成：

```text
地点/主体 | 画面题眼 | 核心事实 | 叙事角度
```

同地点换同义标题、同一多色湖换颜色描述、同一建筑换结构问句，仍属于同一概念族。同一概念族已经出现 2 次时，第 3 次直接淘汰，不得通过改标题或换热点入口规避。

## 3. 来源状态

| 状态 | 允许场景 | 强制格式 |
|---|---|---|
| `[已验证]` | 已实际打开并核验原文 | `[已验证] [来源名·文章标题](https://...)` |
| `[待验证]` | 搜索摘要或尚未打开的线索，只能进入待补清单 | `[待验证] [来源名·文章标题](https://...)` |
| 无可验证来源 | 记录缺口 | `未找到可验证原文` |

禁止用 `https://...`、`example.com`、`example.org` 或虚构文章名充当来源。最终候选只能使用 `[已验证]` 来源。

本地素材路径只用于内部核验记录。用户可见交付使用脱敏文件名或工作区相对路径；公开仓库不得记录用户目录、客户目录或其他绝对路径。

## 4. 双目标评分

- **P 潜力（0–10）**：首图题眼、反常信息量、标题一秒可懂、停留意愿与认知缺口。
- **月报潜力（0–10）**：最新月报/周数据契合、题材配比、时机、差异化与审核稳定性。

仅在 `P>=7` 且 `月报>=8` 时标 `主推`。不可合并成总分或用平均分代替。

## 5. 数据最小化

不创建长期候选池或维护表。真实私有运营指标留在用户本地数据目录；拟公开的 Skill、README、评测 fixture 和 GitHub 仓库只记录通用方法或明确标注的合成数据。
