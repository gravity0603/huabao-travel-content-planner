# 旅行专项数据契约

> 文档版本：v0.8.0
> 适配 Skill：v0.8.0
> 生效日期：2026-09-02

旅行专项同时遵守安装后从本 Skill 目录解析的共享 [`selection-governance.md`](../../huabao-content-planner/references/selection-governance.md) 和本专项的画面、红线、双目标规则。本文件只补充旅行特有要求。

## 1. 按任务决定输入

| 任务 | 必需输入 |
|---|---|
| 批量策划、上线候选审核 | 原始素材库、H 已做表、R 上传表、当前批次候选；周数据/月报用于评分 |
| 标题表达优化 | 已验证的事实、首图题眼、原标题或候选标题；无上游 H/R/B 回执时只能为文字草案 |
| 月报/周数据复盘 | 对应月报、周数据或用户摘录 |
| 来源审核 | 待审核链接与验证状态 |

用户当次素材范围优先于默认时效；目标上线日和至少向前 30 天的 R 去重窗口独立计算。旅行热点默认优先近 30 天只在用户未指定范围时适用；常青/季节素材须说明仍有效原因。

## 2. H/R/B 去重与画面闸门

按共享契约读取 H 全历史、R 近期上传、B 本批/本会话。每条先建原子候选卡，并用以下概念指纹去重：

```text
地点/主体 | 核心事实 | 画面题眼 | 用户收益 | 叙事角度
```

标题句式只用于检查批内表达多样性，不能证明选题新颖。同地点换同义题、同一多色湖换颜色、同一建筑换结构问句，仍可能是同一概念族。H/R/B 任一命中，或同概念族第三次出现，直接淘汰；R 缺失、过期或解析待核时，输出“近期去重覆盖不足”，不可标主推/可上架。

首图必须证明标题承诺，且地点、事实、标题与落地页指向同一对象。普通山海湖日出、普通打卡点和只讲工程参数的设施，不得靠猎奇标题补强。

## 3. 标题与来源

先以 `首图 → 常识预期 → 可见反常/旅行利益点 → 正文答案` 写自然工作稿，再按旅行参考表选择标题打法。标题 ≤7 字、副标题 ≤25 字，疑问句必须用中文 `？`；不能截尾、硬缩或为凑字生造拟人/问句。没有自然合规表达时换切口或淘汰。

最终候选只能用 `[已验证] [来源名·文章标题](https://...)`。搜索摘要仅能进入待补清单；不得使用占位或虚构 URL。

## 4. 质量分、双目标与数据最小化

先通过共享12项硬门槛，再做100分质量评分和 P/月报双目标评分：

- `主推`：质量总分≥85、P潜力≥7、月报潜力≥8，且 H/R/B 与 R 覆盖全部通过；
- `可用`：质量总分75—84，或质量≥85但业务分未达主推门槛；必须说明弱项；
- `修改后复审`：质量总分65—74，仅进入修改清单，不套正式候选模板；
- 低于65或任一硬门槛失败：淘汰或进入对应待补池。

公开仓库不记录私有运营数值、本地路径或候选缓存；本地路径只用于当前工作区核验。
