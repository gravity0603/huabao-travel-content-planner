# 华为画报旅行标题优化手册

> 版本：v0.5.0  
> 最后分析：2026-08-20  
> 样本：用户提供的 `旅行类标题参考.csv`（103 个非空标题）与 `旅行风光.csv`（45 个标题）。
> 用途：把优秀案例的**选题切口与表达机制**转为可执行规范；不把历史标题原样当模板，也不把样本频次误写成 CTR 因果。

## 1. 样本告诉我们的事

### 1.1 标题参考库：短、具体、先给反常

- 103 个标题中，75 个（72.8%）不超过 7 字；41 个（39.8%）为问句；47 个（45.6%）使用引号或把画面翻译成日常物件/动作。
- 高频有效信号不是“神秘”“震撼”一类形容词，而是具体对象发生了违背常识的变化：如“瀑布长了冰胡子”“盐湖长白兔”“海里也有瀑布？”。
- 结论：旅行锁屏标题应先让人看懂**画面里哪里不对劲**，再让人想点开找答案。

### 1.2 旅行风光成品库：机制可借，字数不能照搬

- 45 个标题平均约 8.1 字，仅 20 个（44.4%）不超过 7 字；其中有 9 个问句、13 个数量/排行型表达，且含半角 `?` 的旧写法。
- 它证明地点、时间、数字、强反差和实用问题都能提供切口；但“世界最…/全球五大…/超现实照片”等泛化表达，以及超过 7 字的历史标题，不符合当前旅行专项的出街规则。
- 结论：保留其**可验证的反差、地点与生活问题**，不要直接复制排行腔、空泛形容词或旧标点。

## 2. 旅行选题的最小成立单元

旅行选题不是“某地很美”，而是：

```text
首图可见主体
+ 用户的常识预期
+ 画面中的异常 / 空间反差 / 明确旅行问题
+ 可被原文兑现的答案
```

在写标题前，先写一行事实工作稿：

```text
首图：荒漠中出现湛蓝天然水体
预期：戈壁应当干旱、单色
反常：盐泉形成像眼睛一样的蓝洞
兑现：解释盐泉、地貌与具体地点
```

缺少首图、反常事实或兑现答案的普通山海湖、日落、古镇，只能做素材，不可通过换一个猎奇标题“补强”。

## 3. 标题打法选择表

| 打法 | 适用事实 | 标题结构（非固定模板） | 合规示意 | 不适用 / 风险 |
|---|---|---|---|---|
| 反常问句 | 画面能一眼证明“居然会这样” | 对象/地点 + 异常结果 + `？` | `海里也有瀑布？` | 只有百科解释、首图看不出反常时不用；不用“为何/如何”凑问句 |
| 画面翻译 | 画面形状、颜色或状态确实像日常物 | 地点/对象 + 有证据的比喻/拟物 | `戈壁藏“蓝瞳”` | 比喻必须由首图证明；不为热词硬加引号 |
| 规则/避坑 | 旅行场景中有具体且可信的行为提醒 | 场景物 + 明确后果/提醒 | `纪念品别乱捡！` | 不做无依据的焦虑、脏乱或危险渲染 |
| 空间反差 | 建筑、地貌有可见的上下、内外、尺度或路径反差 | 具体空间 + 违反直觉的关系 | `坐电梯上云端？` | 不能只讲工程参数或施工新闻 |
| 故事钩子 | 有真实人物、历史或使用方式，且首图仍是景观/建筑 | 主体 + 可兑现故事动作 | `守塔人真实生活` | 历史只是解释层；不能只做遗址/文物知识 |

“最、全球、几大、超、神秘、绝美”不是打法，只能在信息足够具体且首图足够强时偶尔作为补充，不能单独承担题眼。

## 4. 标题写法标准

### 4.1 五项自检（每项 0–2 分）

| 项目 | 2 分标准 | 0 分信号 |
|---|---|---|
| 对象锚点 | 标题能看出在说什么地点、景观、建筑或旅行场景 | `超现实照片`、`脑洞大开的设计` |
| 画面证明 | 首图不看正文也能支撑标题的核心承诺 | 标题说“消失”“危险”“最脏”，画面无法证明 |
| 认知缺口 | 有一个具体、可回答的“不合常识”或实用疑问 | 只有“震撼、绝美、神秘”等情绪 |
| 语言自然 | 可一口读完，主谓关系清楚，热词只在语义贴合时使用 | 文言拼接、硬造拟人、为问而问 |
| 事实兑现 | 副标题/落地页可给出明确地点、原因、规则或故事答案 | 标题夸张，正文无答案 |

标题专项建议达到 **8/10** 再进入终稿比较。该分数仅用于表达筛选，不能替代 P 潜力与月报潜力。

### 4.2 字数与标点

- 标题 **≤7 字**，副标题 **≤25 字**；汉字、数字、英文、引号和标点均计入。
- 问句必须以中文 `？` 结尾；半角 `?` 不合规。陈述句、短语和感叹句可用，不强制改成问句。
- 引号只标记确有画面对应的日常化翻译，如“蓝瞳”“冰胡子”；不能把普通词都加引号。
- 同一批中，同一种句式、同一热词或同一引号拟物结构最多 2 条。

### 4.3 标题与副标题分工

- **标题**：只完成一秒识别——“看到什么不寻常/有什么具体问题”。
- **副标题**：补充地点、数量、成因、时间窗口或答案方向，兑现而不复读。
- 不要写成：标题“最奇特的盐湖”，副标题“这是世界上最奇特的盐湖”。
- 应写成：标题给画面钩子，副标题给“它在哪里、为什么这样、点开能得到什么”。

## 5. 选题与标题优化流程

1. **先筛画面**：首图是否有一秒可辨的主体、异常与竖屏题眼；普通美图先淘汰。
2. **再定事实**：用已验证原文写出地点、现象、原因/规则；标题不可超出证据。
3. **再选打法**：按上表只选最贴合的一种，不从“爆款词库”倒推事实。
4. **压缩标题**：删除“世界、最、超、神秘、绝美、盘点”等无信息词，保留对象和反常。
5. **写副标题**：补题眼答案，不重复情绪，不超过 25 字。
6. **批量去重**：检查概念族、地点、画面题眼、句式和热词；不同景点但同一“彩色盐湖/异世界/最美”叙事仍可能重复。
7. **终稿校验**：回到 `SKILL.md` 的封面、来源、三方去重、双目标和审核硬闸门；用 `scripts/validate_candidate_output.py` 检查可机械检查项。

## 6. 常见失分与改法

| 失分 | 为什么不行 | 改法 |
|---|---|---|
| `超现实照片` | 没有对象、地点或可回答的问题 | 先写出画面主体和具体违和点；若仍无题眼，淘汰 |
| `世界最清澈的5个湖泊` | 超过当前 7 字，排行替代了画面发现 | 只在单个湖有可见反常时改为对象 + 反常；否则不做旅行锁屏题 |
| `比萨斜塔会倒塌吗?` | 标题过长且半角问号；问题偏百科，首图难兑现“未来”判断 | 改从首图能证明的倾斜/结构现象切入，或降级为知识内容 |
| `绝美秘境` | 空泛审美，所有景点都可套用 | 给出可见地貌、色彩、空间或季节反差 |
| 生造“也”句 | 模仿“树也会睡觉？”但事实与语言不贴合 | 先检查常识预期是否真实存在；不成立则改为短语或陈述 |

## 7. 终稿前 30 秒清单

- [ ] 首图能在一秒内证明标题最关键的 2–4 个字。
- [ ] 标题有对象/地点锚点和明确反常或旅行利益点。
- [ ] 没有用“最、超、神秘、绝美、震撼”替代事实。
- [ ] 标题≤7字，副标题≤25字；问句为中文 `？`。
- [ ] 副标题补答案，不复读标题。
- [ ] 同批未出现第 3 个同句式/同热词/同概念族。
- [ ] 标题承诺由已验证事实来源、封面和落地页共同兑现。
